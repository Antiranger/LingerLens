# Support

Use GitHub Discussions or an issue for reproducible product questions. Before posting, read the matching language guide, run the narrowest relevant offline check and search existing issues.

Include LingerLens version/build, Windows version, source platform, sanitized reproduction steps, expected and actual behavior, and which checks passed. Remove API keys, Cookie values, account identifiers, signed media URLs, personal paths and raw provider responses. For security vulnerabilities, do not open a public issue; follow [SECURITY.md](SECURITY.md).

Support cannot guarantee a provider account, region-restricted stream, translation quality, exact latency or a billing outcome. Provider outages and account permissions must be checked with the provider.
