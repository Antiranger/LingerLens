# Руководство LingerLens

[Документация](../README.md) · Базовая версия 0.1.0 · Обновлено 2026-09-29

## Запуск

Папка установки Windows по умолчанию — `%LOCALAPPDATA%/Programs/lingerlens`; данные пользователя хранятся отдельно в `%APPDATA%/LingerLens`. Опубликованный установщик 0.1.0 работает в один клик. В следующих установщиках мастер позволит выбрать папку.

Целевые платформы — Windows x64 и macOS arm64/x64. Доступные пакеты находятся в [Releases](https://github.com/Antiranger/LingerLens/releases). В Windows запустите EXE; на Mac откройте DMG для своего процессора и перенесите приложение в «Программы». Предварительные пакеты не подписаны, Mac-пакеты не нотарифицированы. Проверьте файл по `SHA256SUMS.txt`.

Включены Electron, Python, FFmpeg/ffprobe, yt-dlp, шрифты и японский словарь. Облачные аккаунты, оплата API и локальный сервер Whisper с моделью предоставляются отдельно. Данные Mac: `~/Library/Application Support/LingerLens`. На Mac обновление устанавливается из нового DMG; встроенный установщик обновлений работает только в Windows.

Для браузерного режима нужны Python 3.11+, Node.js 22.12+, FFmpeg/ffprobe и Chrome или Edge:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\bootstrap.ps1 -Python .\.venv\Scripts\python.exe
.\start-lingerlens.cmd -Prototype -Python .\.venv\Scripts\python.exe
```

Откройте `http://127.0.0.1:8765/`. `-CheckOnly` только проверяет зависимости. Без `-Prototype` запускается существующая настольная сборка. Не публикуйте Companion в LAN или через обратный прокси.

## Сервисы и просмотр

В настройках подключений укажите точные ID моделей, адреса и авторизацию. Обычно распознавание и перевод раздельны; Qwen LiveTranslate и Soniox могут выполнять их в одной сессии. Перевод поддерживает OpenAI-совместимый протокол, Qwen-MT, Anthropic Messages и Google Gemini; распознавание — DashScope, Soniox, Deepgram, OpenAI, AssemblyAI, Volcano Engine, ElevenLabs, Speechmatics и Tencent. Это список протоколов, а не гарантия каждого аккаунта и языка.

Вставьте HTTPS-ссылку YouTube, Bilibili или Twitch, выберите H.264/AVC и AAC и запустите. Задержка — 11–60 секунд, по умолчанию 15; реальная задержка зависит от источника и сети. Используйте кнопку полноэкранного режима. Публичные эфиры сначала проверяйте без Cookie. Импорт принимает поддерживаемые заголовки, таблицы и Netscape; для входа в Bilibili нужен `SESSDATA`. Cookie не обходят DRM, платный доступ, региональные ограничения или защиту от ботов.

## Как понимать задержку

**Отставание от локальных сегментов** — расстояние от текущего кадра до последнего полного локального видеосегмента. Оно не включает задержку платформы и незавершённые сегменты; при отсутствии измерения показано **—**. **Запас времени при получении перевода** положителен, если перевод пришёл заранее, и отрицателен при опоздании. Учитываются свежие результаты обычного воспроизведения на активной вкладке. Пауза, перемотка, ускоренное воспроизведение и устаревшие данные отменяют прежние рекомендации. Кнопка **Установить целевую задержку 19 секунд** задаёт общую цель 19 секунд. Совет основан на последних наблюдениях и не гарантирует своевременное появление всех последующих субтитров.

## Данные и устранение неполадок

Облачный ASR получает аудио, переводчик — текст и контекст. Данные приложения обычно находятся в `%APPDATA%/LingerLens`; ключи видны в настройках, поэтому не открывайте их при демонстрации экрана и не публикуйте рабочие файлы, подписанные URL или необезличенные журналы. Обновлятор проверяет размер и SHA-256, но не подпись издателя.

Если нет EXE, используйте `-Prototype`; если нет модуля — установите зависимости тем же Python; при занятом порте закройте нужный Companion или выберите другой; при 403 и отсутствии форматов проверьте URL, аккаунт, регион и Cookie; при отсутствии субтитров проверьте профили и языки.
