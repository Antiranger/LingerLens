## 文本复查与未解决问题

- 回归保护：`3, | 4 guys`、`the traditional conservative party, | has stuck to it`、`学校1の美人の、 | 女の子…`、`すごく、 | 海も…` 等已知反例在评分测试中被拒绝。
- 英语仍存在不理想切点。例如 en-D 的 `…culture, you know, | a lot of power in this state.`，口头填充语被当成谓语证据；en-B 的长嵌套结构仍可能在主句未完成时切开。没有全面人工标准答案，不能报告准确率提高了多少。
- 日语仍有 18.60 秒的长片段。保持形态保护意味着保留了漏切；本轮没有解决日语长句。
- 英语仍有无中途标点的 10.98 秒、11.34 秒句子；以及 17.64 秒长句。候选评分不能为没有可靠证据的位置凭空增加边界。
- 已可见的短尾可以合并；未来才来的 `Dougie.` 等短尾仍可能单独出现。不为避免短尾引入额外等待。
- 本轮数据参与过规则调整，是开发集回放，不是独立盲测。中韩西葡仅人工对照，不能声称实测多语言普遍有效。

## 校验与复现

- 单元测试：评分器 10 项、现有切句器 35 项、现有语言切句 16 项，共 61 项通过。
- `verify_streaming.py`：同时说话相同文字保留、原时间戳、旧代事件丢弃、最终残片过期释放通过。
- 每轮回放断言：稳定文字守恒；ASR 单元无漏、无重、每说话人顺序一致；原始时间映射；对照单元账本一致。
- 回放脚本记录源数据和相关源文件 SHA-256；当前源代码运行路径未切换。

```powershell
$env:PYTHONUTF8='1'
python .scratch/candidate-scorer-evaluation/experiment.py
python .scratch/candidate-scorer-evaluation/verify_streaming.py

```
