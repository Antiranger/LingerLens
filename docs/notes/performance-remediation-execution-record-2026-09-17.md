**R1 已完成（`85420f2`），但只修「可确认的那一类」。** 四个文件必须一起改：probe 拥有本腿时钟（O(1) 状态：上一个可信 raw tick、回绕计数、`clock_valid`/`invalid_reason`），`ytdlp_ingest` 逐腿暴露并聚合成 `sourceClockValid`/`sourceClockReason`，`server` 的首次原点差改为模一个周期、并在取偏移前检查可信性，`media_anchor` 增加 `sampled_fallback_allowed`（默认 true）。**改动前的实测**：同一段跨边界序列得到 `95442.717689, 95443.217689, 0.0, 0.5, 1.0`——一步 **−95443.2 秒**，`sourcePtsLast − sourcePtsFirst` 因此是 **−95441.7 秒**（负数进度）；同一对原点 `_source_clock_offset()` 返回 None（真值 +5 秒）；精确偏移被拒后 anchor 仍然从采样窗发布了 5.0。改动后：五步全是 +0.5、extent +2.0、偏移 5.0（误差 ≤1 tick）。400 步 ×500 秒跨边界三次，整数展开**零漂移**。

**歧义没有被解决，也没有被声称解决。** 首个原点落在 mpegts 复用器 1.4 秒 re-base 窗内，正是回绕后「合法时钟起点」的样子，两个数字无法区分；按批准的行为它被**明示为不可确认**（`origin-rebase-or-wrap-ambiguous`），不使用取模硬凑。2 秒守卫未动。要真正区分需要边界前后两腿的真实 PES PTS 与 discontinuity 标记——合成回放给不出这个。所以：**可确认的回绕路径已修；全天对齐不作保证。**

**顺带在自己的实现里发现并补上的两个缺口**（都由测试抓出，都已覆盖）：① 没有腿（未启动／已停止）的 ingest 会报 `sourceClockValid: False / no-legs`，若当成「不可信」就会为一个从未存在过的时钟关掉采样回退——它是「未测到」；② 拒绝记录原本挂在应用对象上，一次 discontinuity 会让**整个进程余生**都关着采样回退，现由 `_reset_source_clock()` 与原点锁存一起重置。

**同步说明的不回归**：正常同侧对齐（27886.406 / 27881.4 → 5.006）、小幅 PTS 倒退容忍、`test_media_anchor.py` 原有的「无 provider 保持原行为」等用例全部保持。回退方式按计划要求：R1 是**一个提交**，probe／ingest／server／anchor 必须一起回退——只回 probe 会让消费者继续把 raw 当展开值用。

### 3.1 一次压缩失误，值得单独记下

用户报过三件事：①「鼠标不跟手 / 界面卡」②「点另一个屏幕的 Edge，整机卡死」③**「越跑越卡」**。

我写的那份[简报](performance-remediation-brief-2026-09-17.md)（`9d58ab1`，给"只能读仓库的外部模型"看的）**只写了 ①②**。③被漏掉了。

后果的传播方式是这样的：

```
简报漏掉 ③
  → 决策文档只覆盖简报里的十个编号，它无从覆盖 ③
    → 它写了一段完整的"明确选择不查什么"，里面同样没有 ③
      → M1 按决策文档的范围做，没有 ③
        → 执行记录与工作单都继承了同一个缺口
```

**每一份文档都是忠实的，没有一份能发现这个缺口。** 直到用户本人问起。

这不是"漏写一句话"，而是**把需求压缩成交付物时丢掉顶层需求**的一次实例：我的简报是唯一见过完整抱怨的地方，而它做了信息损失，且损失不可见。下游越严谨，越会把"我被告知的范围"当成"存在的范围"。

**具体教训（供规划模型参考）：** 任何声称"覆盖了全部现象"的清单，都应该能回答"这个清单是从哪里来的、原始输入有几条"。本轮所有文档都答不上这个问题。

**`D0` 的处理（已落地）。** 这一节不只是记录事故，它换来了两件可执行的东西：① §0 的**顶层需求登记表** —— U1/U2/U3 各自带所有者、状态、证据、下一步，并且立了"每次交接逐行对照本表、未承接条目必须写不做＋理由＋归属、新抱怨追加为新行"三条规则；② 四处文档的**证据措辞降级**（把"排除"改成"限制"、把"消除"改回"修了一个机制"、把 75 从"失败次数"改成"已记录的失败行数"）。**验收方式**：拿 U3 去查 §0，必须能落到 L1 的测量与"未验收"状态——而在这一轮之前，整条交付链里没有任何一处能承接它。
