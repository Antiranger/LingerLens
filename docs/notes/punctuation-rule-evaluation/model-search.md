# 日语字幕切分模型核对记录

日期：2026-09-07。目标是确认前面提到的 FBK Multimodal Subtitle Segmenter 是否支持日语，并寻找更贴近字幕内部换条的公开替代品。仅做公开资料核对，没有下载训练 checkpoint 或接入生产。

## FBK 模型的实际语言范围

作者的[官方模型说明](https://github.com/hlt-mt/FBK-fairseq/blob/master/fbk_works/SUBTITLE_SEGMENTER_AACL2022.md)列出的 `de_en_fr_it` 和 `all_langs` 结果表只有：德语、英语、西班牙语、法语、意大利语、荷兰语、葡萄牙语、罗马尼亚语。

因此，前面所说的“8 种语言没有英语”是不准确的：**英语在这八种语言中**；**日语不在发布的八语言模型范围内**。作者 README 的训练命令也只以 `en,de,fr,it` 作为训练语言，`es,nl` 作为未见语言测试示例；没有日语 checkpoint 或日语结果。

论文 [Papi et al. 2022](https://aclanthology.org/2022.aacl-short.59.pdf) 描述的模型是文本编码器加音频编码器的多模态字幕 segmenter，输入音频和文字并生成 `<eol>/<eob>` 标记。它确实比上一轮 WtP/SaT 更贴近“字幕换条”，但公开说明没有实时流式延迟承诺，部署依赖 Fairseq 和音频特征，不能当作一个轻量日语文字模型。

## 找到的日语替代方向

1. **WtP/SaT 的日语能力已经在本地测过**：它们的 tokenizer／模型覆盖日语，但本轮长句内部切分表现不足；这不是“没有日语支持”，而是任务匹配度不够。
2. **DISRPT/EDU 分句模型**（例如[DisCoDisCo](https://github.com/gucorpling/DisCoDisCo)）学习句内语义单元边界，概念上比句号检测更接近长句分段。官方实现需要 AllenNLP、上下文特征和训练数据；它是话语分割模型，不是现成的日语实时字幕换条模型。仓库没有提供一个可直接下载运行、已验证日语直播的轻量 checkpoint。
3. 进一步搜索了日语字幕切分、日语预训练断句和多语言字幕 segmenter。找到的公开资料主要是通用日语预训练模型、形态素／句界工具、离线字幕项目或研究代码，没有同时满足“日语、字幕内部换条、保留原文时间、公开权重、实时运行”的现成小模型。

## 结论

目前不能诚实地说“这个 FBK 模型可以直接拿来测试日语”：它没有发布日语支持。可以测试它的英语或西班牙语，但那回答不了当前日语问题，而且它的多模态运行时会明显改变实验条件。

对于日语，当前最可靠的低延迟路径仍是**保留原始 ASR 时间的程序规则**，必要时结合日语形态素边界和已确认的停顿／句末证据。模型路线并没有被否定；如果要做模型，应针对我们的直播字幕边界建立日语标注，再微调一个逐 token 边界分类器，或把 EDU 模型改造成只在已确认 ASR 单元边缘打分。这是需要训练和单独延迟验证的项目，不是下载一个现成模型即可完成的补丁。

本核对覆盖了 FBK 官方代码仓库与模型说明、ACL 论文正文、DisCoDisCo 官方仓库以及日语 NLP 资源搜索。未覆盖私有商业模型、未公开 checkpoint 和需要登录的模型市场；也没有声称“互联网不存在其他模型”。
