# 残片生命周期修复：实现与离线验收

日期：2026-09-07。代码已修改，未重启正在运行的 Companion。此次新增 ASR 调用 0 次、翻译调用 0 次。

## 已实现

- 重复/过期事件先检查，避免清理了残片却未返回文字。
- 文字实际音频终点与输入音频进度分离；续接使用本次新接受文字的时间，不使用整条观察的起点。
- 已完成识别的残片有 1.2 秒本地续接机会；同说话人、同语言、跨条目且音频间隔不超过 1.2 秒才能续接，明显重叠的不同条目也独立输出。
- 一个会话级可取消计时任务处理期限，无新识别、无新音频时仍可收尾。完整句立即输出，尚在进行的识别不因音频推进或单纯经过时间被强切。
- NFKC 仅用于一致比较；保留原始逐字文字/时间。已稳定文字使用精确时间身份去重，快照稳定判断继续容许小幅抖动。
- 修复日语“谓语连体形＋句末の＋问号”以及英语数字句末漏判；保留助词/助动词、小数、独立编号和缩写保护。

## 参数对照与边界

|final后续接等待|音频续接间隔上限|八路残句收尾数量|
|---:|---:|---:|
|0.0 秒|1.2 秒|294|
|0.3 秒|1.2 秒|294|
|0.6 秒|1.2 秒|294|
|1.2 秒|1.2 秒|283|
|2.0 秒|1.2 秒|271|

0、0.3、0.6秒在这些轨迹上没有取得不同的续接分区。1.2秒比0秒减少11次残句收尾，含日语“……ドールの方にさ。ずっと。バグってる。”的续接；在1.2秒等待下，把音频间隔上限放宽到2秒没有增加收益，因此选择两个含义独立的1.2秒上限。更长等待也会接入应答或感叹，不能把“合并更多”当成正确率。完整候选见continuations.json。

1.2秒是当前样本上的折中，并非已完成听音验证的最优值。它限制没有合格续文时的额外等待；已接受真正续文后可继续组织表达，所以不是每个旧字都保证在其final后1.2秒内显示。本轮候选的已完成条目文字最大后续等待约2.231秒。

性能数字只测本地切句回调，排除了离线序列化耗时；各路P95仍在约0.09—0.15毫秒。部分英语来源有约0.015毫秒的额外成本，未观察到毫秒级持续性能退化。待处理单元数有所减少或持平，但这不是完整进程长期堆内存测试，也不包含实际翻译和上屏耗时。
