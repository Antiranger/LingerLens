### 2.1 `ce1e47e` —— B2（你的 §3.2）

**做了什么。** 复用了链自己的禁用/冷却/输入上限判断，抽成 `FallbackChain._could_try_any()`；预留量 `reserve` 只在"后面确有可尝试的 provider"时才等于 `fallback_reserve_seconds`；当 `0 < R ≤ reserve` 时**跳过主服务**并把整个剩余时间交给兜底；跳过时往 `errors` 里写一条 `RuntimeError("skipped: …")`，**不触碰任何 health 状态**。

**我偏离你设计的一处（有意，请判断对不对）。** 你的条件表第一行是 `R ≤ 0 → 不再发新 provider 请求`。我查证后**没有实现它**：`subtitle_pipeline.py:1236` 与 `:1288` 在调用链之前就已经 `remaining <= 0 → raise TranslationDeadlineExpired("…")`，所以 `R ≤ 0` 到不了链里；自己再加一条到期路径只会制造一个与既有分类不一致的第二种"到期"。
