<p align="center"><strong>Понимайте прямой эфир с субтитрами.</strong></p>

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [Deutsch](README.de.md) · [Русский](README.ru.md)

Дайте субтитрам время догнать речь. LingerLens воспроизводит прямые трансляции **YouTube Live, Bilibili Live и Twitch** с локальной задержкой, добавляя распознавание речи, перевод субтитров и чат рядом с видео.

**Предварительная версия для Windows и macOS · Код приложения под MIT · Нужны собственные ключи API.** Доступность трансляций и языков зависит от платформы, учётной записи и сервиса.

## Скачать

[**GitHub Releases →**](https://github.com/Antiranger/LingerLens/releases)

Для Windows x64 выберите `.exe`. Для Mac — `macos-arm64.dmg` (Apple Silicon) или `macos-x64.dmg` (Intel). Откройте DMG и перенесите LingerLens в «Программы». Доступны вложения опубликованных релизов. Предварительные сборки не подписаны; сборки macOS не нотарифицированы. Контрольные суммы находятся в `SHA256SUMS.txt`.

## Зачем задерживать видео?

Распознавание и перевод занимают время. LingerLens немного задерживает изображение, чтобы речь и перевод появлялись вместе. Начните с 15 секунд и настройте задержку под сервис и сеть.

## Возможности

- Локальное воспроизведение HLS с целевой задержкой от 11 до 60 секунд; по умолчанию — 15 секунд. На фактическую задержку также влияют платформа и сеть.
- Субтитры с оригиналом и переводом, включая одновременную речь, если сервис передаёт сведения о говорящих.
- Профили распознавания, перевода и резервных моделей, необязательный перевод чата, оценка расхода и стоимости при наличии данных.
- Перемещаемое окно субтитров с сохранением оформления, полноэкранный режим всего плеера, диагностика и проверка обновлений.
- Интерфейс на упрощённом китайском, английском, японском, немецком и русском. Его язык не определяет языки субтитров.

## Начало работы

Установите пакет для своей системы и откройте **LingerLens**. В комплект входят Electron, Python, FFmpeg/ffprobe, yt-dlp, шрифты и японский словарь; инструменты разработчика не нужны. Для облачных сервисов нужны интернет, свои ключи API и оплата при необходимости. Локальный сервер Whisper и веса модели не включены.

Подробности: [руководство на русском](docs/ru/guide.md) и [сборка для Windows и macOS](desktop/README.md).

1. Откройте настройки подключений и ключей и настройте распознавание и перевод.
2. Выберите язык речи и язык перевода, при необходимости включите субтитры.
3. Вставьте ссылку на трансляцию, получите варианты качества и запустите совместимый формат.
4. Импортируйте Cookie только при необходимости авторизации. Перед сменой аккаунта или обновлением остановите воспроизведение.

[Руководство на русском](docs/ru/guide.md) описывает настройку, сервисы, Cookie, конфиденциальность, устранение неполадок и разработку.

## Запуск из исходного кода

Нужны Windows, Python **3.11+**, Node.js **22.12+**, FFmpeg/ffprobe в PATH и Chrome либо Edge. Пока репозиторий закрыт, для клонирования требуется доступ через GitHub.

```powershell
git clone https://github.com/Antiranger/LingerLens.git
cd LingerLens
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\bootstrap.ps1 -Python .\.venv\Scripts\python.exe
.\start-lingerlens.cmd -Prototype -Python .\.venv\Scripts\python.exe
```

Откройте <http://127.0.0.1:8765/>. Bootstrap проверяет инструменты и контрольную сумму yt-dlp, затем устанавливает зависимости. `-CheckOnly` оставляет только проверки. Сборка приложения при этом не создаётся.

Без `-Prototype` команда запускает существующий `release/win-unpacked/LingerLens.exe`. Для его создания см. [инструкцию по сборке](desktop/README.md).

## Конфиденциальность и ограничения

Облачное распознавание получает аудио, перевод — текст и контекст. В режиме встроенного двуязычного распознавания аудио и инструкции перевода получает один сервис. Локальный Whisper-совместимый сервер устанавливается отдельно; он не отменяет отправку текста облачному переводчику.

Ключи и Cookie сохраняются в обычных локальных файлах, а не в зашифрованном хранилище. **В настройках видны сохранённые ключи.** Не открывайте их при демонстрации экрана и не прикладывайте рабочие данные или непроверенные журналы к Issue. Данные обычно находятся в `%APPDATA%/LingerLens` и сохраняются после удаления программы.

LingerLens не обходит DRM, платный доступ, ограничения аккаунта и защиту от ботов. Стоимость сервисов, изменения платформ и качество перевода требуют отдельной проверки. Локальные тесты не подтверждают работу со всеми реальными аккаунтами.
